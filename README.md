## Getting Started

Requirements: Node.js and npm.

```bash
git clone https://github.com/febbyyyyh/portfolio-febby.git
cd portfolio-febby
npm install
npm run dev
```

The development server prints its local URL after it starts.

## Portfolio Content

- Update project titles, descriptions, technologies, highlights, and screenshot paths in [`src/lib/projects.ts`](./src/lib/projects.ts).
- Update profile, experience, certification, and section content in [`src/routes/index.tsx`](./src/routes/index.tsx).
- Replace or add visual assets in `public/assets/`.
